# 🏅 Olympics Data Analysis Web App

An interactive **Exploratory Data Analysis (EDA)** web application built using **Python**, **Streamlit**, and **Plotly** to analyze historical Olympic Games data. The application provides insightful visualizations and statistics about athletes, countries, sports, events, and medal tallies.

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the historical Olympic Games dataset and presents the insights through an interactive Streamlit dashboard.

Users can explore:

- 🏆 Medal tally by country and year
- 🌍 Country-wise Olympic performance
- 👨‍🎓 Athlete participation statistics
- 🏅 Sport and event analysis
- 📈 Participation trends over the years
- 🎯 Age, height, and weight distribution of athletes
- 📊 Interactive charts and visualizations

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/ash972-cpu/Data-Analysis-web-App.git
```

Move into the project directory

```bash
cd Data-Analysis-web-App
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
